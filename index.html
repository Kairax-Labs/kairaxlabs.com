Multi-Agent AI Treatment Reviewer

Autonomous Collaborative Medical Board with RAG & Tool-Calling

Architectural Overview

An autonomous 3-agent clinical consultation board built with LangGraph. Agents collaborate through cyclical state validation to review patient medication plans, eliminate toxic drug-drug interactions, and ensure strict alignment with WHO medical guidelines.

┌──────────────────────────────┐ │ Supervisor Agent (Lead) │ └──────────────┬───────────────┘ │ ┌──────────────┴───────────────┐ ▼ ▼ ┌─────────────────────────────┐ ┌─────────────────────────────┐ │ Clinical Pharmacist Agent │ │ Medical Compliance Officer │ │ • Tool: DDI Interaction API │ │ • RAG: ChromaDB WHO Corpus │ │ • Toxicity index scoring │ │ • Gemini Vector Embeddings │ └─────────────────────────────┘ └─────────────────────────────┘ ▲ ▲ └──────────────┬───────────────┘ ▼ ┌──────────────────────────────┐ │ Consensus & Verified Plan │ └──────────────────────────────┘

Core Technical Modules

  • LangGraph Cyclical State Machine: Dynamic routing between Supervisor, Clinical Pharmacist, and Compliance Officer.
  • Semantic RAG Pipeline: LangChain and ChromaDB populated with official WHO clinical guidelines, indexed with Google Gemini Embeddings.
  • Autonomous Tool-Calling: Automated pharmacology database lookups to isolate adverse drug-drug interactions with 0% hallucination tolerance.
  • Hugging Face Spaces CI/CD: Deployed as a Gradio web application with automated GitHub Actions testing and continuous integration.
